# FastAPI Notes API & Webhook Dispatcher

A lightweight RESTful backend service built with **FastAPI**, **Supabase (PostgreSQL)**, and **n8n**. This base template implements full CRUD operations for notes with persistent cloud database storage and asynchronous outbound webhook event dispatching.

## Features

- **RESTful CRUD API:** Full `GET`, `POST`, `PUT`, and `DELETE` endpoints on `/notes` with automatic OpenAPI documentation (`/docs`).
- **Schema Validation:** Request and response validation powered by Pydantic (`NoteIn` and `Note`).
- **Persistent Cloud Storage:** Stores note records in a Supabase PostgreSQL table (`notes`).
- **Async Outbound Webhooks:** Dispatches non-blocking JSON payloads via `httpx.AsyncClient` to an external webhook URL (such as n8n) on every `note.created`, `note.updated`, and `note.deleted` event.

## Tech Stack

- **Framework:** Python 3.11+, FastAPI, Uvicorn
- **Validation:** Pydantic v2
- **Database:** Supabase (PostgreSQL)
- **HTTP Client:** HTTPX (Async)
- **Automation:** n8n (Webhook Trigger)

## Database Setup (Supabase)

Run the following SQL query in your Supabase **SQL Editor** to create the `notes` table:

```sql
CREATE TABLE notes (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title TEXT NOT NULL,
    content TEXT DEFAULT '',
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## Local Setup & Installation

### 1. Clone the Repository
```bash
git clone https://github.com/alifanovelia05/notes-api-webhook.git
cd notes-api-webhook
```

### 2. Create & Activate Virtual Environment
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 3. Install Dependencies
```powershell
pip install -r requirements.txt
```

### 4. Configure Environment Variables
Create a `.env` file in the root directory:
```env
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_KEY=your-supabase-secret-key
WEBHOOK_URL=https://your-n8n-instance/webhook/your-webhook-id
```

### 5. Run the Server
```powershell
uvicorn main:app --reload
```
Open **`[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)`** to test the endpoints via Swagger UI.

## API Endpoints

| Method | Endpoint | Description | Webhook Event |
| :--- | :--- | :--- | :--- |
| `GET` | `/notes` | Retrieve all notes ordered by `id` | None |
| `POST` | `/notes` | Create a new note | `note.created` |
| `PUT` | `/notes/{note_id}` | Update an existing note by ID | `note.updated` |
| `DELETE` | `/notes/{note_id}` | Delete a note by ID | `note.deleted` |

## Example Webhook Payload

Whenever `POST`, `PUT`, or `DELETE` succeeds, the server sends a JSON payload to `WEBHOOK_URL`:

```json
{
  "event": "note.created",
  "data": {
    "id": "1",
    "title": "Meeting Notes",
    "content": "Discuss backend architecture"
  }
}
```
