# Central Ticket Intake Hub & Webhook Dispatcher

A decoupled, event-driven RESTful backend service built with **FastAPI**, **Supabase (PostgreSQL)**, and **n8n**. This service acts as a centralized intake gatekeeper for multi-channel support tickets, enforcing strict payload validation, persistent cloud database storage, and authenticated asynchronous webhook dispatching for priority-based escalation.

## Features

- **Multi-Channel Ticket CRUD API:** Full `GET`, `POST`, `PATCH`, and `DELETE` endpoints on `/tickets` (with query filtering by `status` and `priority`) and automatic OpenAPI documentation (`/docs`).
- **Gatekeeper Validation & Normalization:** Request and response validation powered by Pydantic v2 (`TicketCreate`, `TicketUpdate`, `TicketOut`) with `EmailStr`, strict `Literal` categories, and automatic string trimming/lowercasing.
- **Persistent Cloud Storage:** Stores centralized ticket records in a Supabase PostgreSQL table (`tickets`) as the single source of truth.
- **Authenticated Outbound Webhooks:** Dispatches non-blocking JSON payloads via `httpx.AsyncClient` secured with a static shared secret header (`X-Webhook-Secret`) on every `ticket.created`, `ticket.updated`, and `ticket.deleted` event.
- **Priority-Based Event Routing (n8n):** Filters out deletion events, routes `high` priority tickets to instant Telegram alerts (with auto-retry), and queues `normal`/`low` tickets separately.

## Tech Stack

- **Framework:** Python 3.11+, FastAPI, Uvicorn
- **Validation:** Pydantic v2 (`EmailStr`, `Literal`, `@field_validator`)
- **Database:** Supabase (PostgreSQL)
- **HTTP Client:** HTTPX (Async)
- **Automation & Alerting:** n8n (Webhook Trigger, If, Switch) & Telegram Bot API

## Database Setup (Supabase)

Run the following SQL query in your Supabase **SQL Editor** to create the `tickets` table:

```sql
CREATE TABLE tickets (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    sender_name TEXT NOT NULL,
    sender_email TEXT NOT NULL,
    source TEXT NOT NULL CHECK (source IN ('web_form', 'telegram_bot', 'internal_app')),
    priority TEXT NOT NULL DEFAULT 'normal' CHECK (priority IN ('low', 'normal', 'high')),
    status TEXT NOT NULL DEFAULT 'open' CHECK (status IN ('open', 'in_progress', 'resolved')),
    message TEXT NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## Local Setup & Installation

### 1. Clone the Repository
```bash
git clone https://github.com/alifanovelia05/notes-api-webhook.git
cd notes-api-webhook
```

### 2. Create & Activate Virtual Environment
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 3. Install Dependencies
```powershell
pip install -r requirements.txt
```
*(Ensure `email-validator` is included in `requirements.txt` for Pydantic `EmailStr` support.)*

### 4. Configure Environment Variables
Create a `.env` file in the root directory:
```env
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_KEY=your-supabase-secret-key
WEBHOOK_URL=https://your-n8n-instance/webhook/your-webhook-id
WEBHOOK_SECRET=whsec_your_random_shared_secret
```

### 5. Run the Server
```powershell
uvicorn main:app --reload
```
Open **`[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)`** to test the endpoints via Swagger UI.

## API Endpoints

| Method | Endpoint | Description | Webhook Event |
| :--- | :--- | :--- | :--- |
| `GET` | `/tickets` | Retrieve all tickets (supports `?status=` and `?priority=` filters) | None |
| `GET` | `/tickets/{ticket_id}` | Retrieve a single ticket by ID | None |
| `POST` | `/tickets` | Validate, normalize, and create a new ticket | `ticket.created` |
| `PATCH` | `/tickets/{ticket_id}` | Update `status`, `priority`, or `message` of an existing ticket | `ticket.updated` |
| `DELETE` | `/tickets/{ticket_id}` | Delete a ticket by ID | `ticket.deleted` |

## Example Webhook Payload

Whenever `POST`, `PATCH`, or `DELETE` succeeds, the server sends a JSON payload to `WEBHOOK_URL` along with the `X-Webhook-Secret` header:

```json
{
  "event": "ticket.created",
  "data": {
    "id": 1,
    "sender_name": "Raka Wijaya",
    "sender_email": "raka.security@enterprise.id",
    "source": "internal_app",
    "priority": "high",
    "status": "open",
    "message": "Latency spike detected on production checkout endpoint.",
    "created_at": "2026-11-18T03:15:00+00:00"
  }
}
```
